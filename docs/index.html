Diso 4.3.1

Nguồn Sileo đã online. Package tên Diso (máy rootless / Dopamine).

Cách 1 — Thêm nguồn Sileo 
https://vpnhihi.github.io/diso/
  1. Sileo → Sources → +
  2. Dán link → Add
  3. Làm mới nguồn
  4. Vào Sources → Diso hoặc Search gõ Diso
  5. Bấm cài Diso

Lưu ý: app Diso không tự hiện ngoài màn hình chính cho đến khi bạn cài xong trong Sileo.

Cách 2 — Tải .deb cài trực tiếp

Tải Diso_4.3.1.deb

Mở file bằng Filza hoặc Sileo để cài. Chỉ hỗ trợ jailbreak rootless, iOS ≥ 15.
